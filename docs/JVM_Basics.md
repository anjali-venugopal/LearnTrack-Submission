# JVM Basics
## What is JDK, JRE, JVM
## JDK, JRE, and JVM

**JVM (Java Virtual Machine)** is the engine that executes Java bytecode. When we execute a .class file, the JVM reads the bytecode and translates it into machine-specific instructions for our operating system. Provides platform independence.

**JRE (Java Runtime Environment)** has everything to run Java application, it includes the JVM + the standard class core libraries needed to run Java applications. we can only run but not build here

**JDK (Java Development Kit)** has everything to develop Java applications, it includes  everything in the JRE + development tools such as javac (the compiler), jar, debugging utilities (jdb), Javadoc and more
In short: you write code with the JDK, compile it to bytecode, and the JVM (part of the JRE) executes that bytecode.


## What is bytecode?
It is an intermediate representation of Java Source code, generated by java compiler and it is platform independent.

When you compile a .java file with javac, the compiler does not produce native machine code for your CPU. Instead, it produces **bytecode** — a platform-independent instruction set stored in .class files.

The JVM interprets (or JIT-compiles) bytecode at runtime. This is why the same compiled .class file can run on any system that has a compatible JVM.

## What does “write once, run anywhere” mean

"Write once, run anywhere" (WORA) is a core promise of Java. You compile your source code **once** into bytecode, and that bytecode can run on any device or OS that has a JVM — without recompiling for each platform.

This works because the JVM acts as an abstraction layer between your program and the underlying hardware. Your code targets the JVM's bytecode instruction set, not a specific processor or operating system. As long as a JVM exists for the target platform, your application can run there with the same compiled `.class` files.

The trade-off is a small runtime overhead compared to natively compiled languages, but in return you get portability and consistent behavior across environments.
